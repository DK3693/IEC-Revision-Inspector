# Public portfolio materials

The public package contains executable analysis source, technical documentation and synthetic interface examples. It intentionally excludes private PDFs, extracted text, real reports, logs, caches, document crops, organisation logos and local filesystem metadata.

The public illustrations are recreated from fictitious text and opaque placeholder bars. They contain no embedded private document image or hidden original text. No confidential page is protected merely by applying a reversible blur or a CSS overlay.

The selected-result table contains aggregate values only. It reports one observed document-pair execution and does not assert independently measured semantic accuracy.

The default model endpoint is localhost. Selecting a remote endpoint sends the analysis input to that configured server. Generated reports, JSON and page images contain source-derived content and should remain in the document owner's authorised environment.

Git ignore patterns help prevent accidental staging of runtime artifacts; they do not sanitize files that have already been committed. Publish from this isolated package rather than the working document folder.
